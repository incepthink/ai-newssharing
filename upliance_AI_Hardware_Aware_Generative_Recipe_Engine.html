Upliance AI: Hardware-Aware Generative Recipe & Personalization Engine
System Architecture & Compiler Specifications for the upliance Smart Appliance
Problem
Context & Physical Hardware Constraints

The upliance smart cooking hardware operates via precision physical actuators—motorized stirring blades, induction heating elements, and integrated weighing sensors. However, the appliance initially relied on static, hardcoded recipe programs that could not accommodate real-world kitchen variables: dietary requirements (keto, vegan, Jain), missing pantry items, custom portion sizes, or personal spice tolerances. Generic conversational LLMs (such as standard chatbots) cannot safely solve this, as unconstrained text generation cannot safely translate into the strict thermal limits, blade speeds, and timed physical steps required by physical kitchen hardware.

Solution

Engineered upliance AI, an intelligent, hardware-constrained recipe personalization and compiler engine that translates natural language culinary requests into safe, machine-executable cooking workflows:

  • Semantic Recipe Discovery (AI Vector Search & Retrieval): Powers dynamic recipe discovery across the verified upliance recipe database using semantic vector embeddings (pgvector). Ingests user dietary profiles, available pantry ingredients, and time constraints to match and retrieve optimal kitchen-tested base recipes based on culinary meaning and flavor profiles rather than rigid keywords.
  • Context-Aware Recipe Adaptation Engine: Developed an intelligent culinary reasoning pipeline using a self-hosted private AI model (Qwen LLM on private vLLM infrastructure). When a user requests on-the-fly modifications (e.g., "make this low-carb, swap paneer for tofu, and adjust for 4 people"), upliance AI dynamically recalculates ingredient proportions, liquid-to-solid moisture balance, and cooking duration.
  • Deterministic Machine Instruction Compiler: Enforces strict data-validation rules (via Zod schemas) to compile natural language cooking steps into exact, deterministic machine controls:
    • Motor Speeds: Stirring RPM, reverse blade mode (stirring with the blunt edge to gently mix without shredding delicate ingredients like paneer or tofu), and pulse chopping cycles.
    • Multi-Stage Induction Heat Curves: Gradual, controlled temperature ramps and timed hold intervals to prevent burning or scorching.
    • Integrated Scale Calibration: Step-by-step weight prompts with automated tare calibration (automatically zeroing the scale as ingredients are added).
    • Hardware Safety Envelopes: Enforced physical guardrails (scorch prevention, dry-run cutoffs, and boil-over mitigation).
  • Real-Time Appliance Synchronization: Connects upliance AI to the appliance's touchscreen operating system via lightweight real-time communication protocols (WebSockets), delivering live interactive cooking guidance, automated appliance actuator control, and responsive feedback to user taste adjustments.

Platform Engineering Highlights & Hardware Guardrails
Institutional Safety Standards for Kitchen Automation
  • Hardware-Aware Culinary Reasoning: Unlike generic conversational chatbots that generate ungrounded recipes, upliance AI incorporates physical kitchen physics—calculating evaporation rates, induction thermal inertia, and blade shear resistance before generating instructions.
  • Reverse Blade Texture Preservation: Automatically deploys reverse blade rotation (stirring with the blunt edge of the blade) during delicate simmering stages, preventing soft proteins like paneer, tofu, or vegetables from being pureed.
  • Fail-Safe Firmware Interlocks: All compiled machine parameters pass through local microcontroller firmware checks. If sensors detect insufficient liquid (dry-run risk) or abnormal temperature spikes, the induction heater immediately cuts off independently of cloud software.
  • Closed-Loop Interactive Weighing: Synchronizes recipe steps with integrated load-cell scales, pausing execution until the user reaches the exact ingredient weight target and automatically zeroing (tare calibration) for the next step.
